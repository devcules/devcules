# Code of conduct

Devcules is built in the open and everyone is welcome.

- Be respectful: assume good intent, disagree without demeaning, and
  keep criticism on the work, not the person.
- No harassment, hate speech, or unwelcome sexual attention, in any
  project space.
- Keep it safe: no secrets, credentials or personal data in issues,
  PRs or chat.
- Maintainers uphold this policy. Behaviour that breaks it can lead to
  a warning, a temporary ban, or a permanent ban, decided by the
  maintainers and communicated privately.
- To report a problem, contact the maintainers privately (a private
  vulnerability report on GitHub reaches them). Reports are kept
  confidential.
